# Velvet Interpolator 0.1.0

Status: installable, not yet tested on an MPC. The screen skin (TUI.json and images) is in the package.
Until it has been run on a device, treat it as unverified: see TEST_ON_MPC.md.

To install, copy the whole package folder to the MPC, then run as root on the device:

    sh install.sh

The installer stops MPC while it works and restarts it afterwards. Save your project first.
